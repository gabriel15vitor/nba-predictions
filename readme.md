## Configuração

Este projeto utiliza um arquivo `application.properties` para armazenar configurações sensíveis como credenciais do banco de dados e chave de API. Este arquivo não está incluído no repositório por questões de segurança.

Para rodar o projeto localmente:

1. Navegue até `src/main/resources/`
2. Copie o arquivo `application.properties.example` e renomeie para `application.properties`
3. Preencha os valores com suas próprias credenciais:
   - URL, usuário e senha do PostgreSQL
   - Sua chave de API do balldontlie.io
